# One-Day To-Do

A minimal single-day to-do app for iPhone (and Android-ready), built with Expo.

See [TODO_APP_SPEC.md](./TODO_APP_SPEC.md) for the full product and technical spec.

## Development

```bash
npm install
npx expo start
```

Scan the QR code with the iPhone Camera app to open it in **Expo Go**. Phone and PC must be on the same Wi-Fi network (use `npx expo start --tunnel` if not).

## Tests

```bash
npm test
```
